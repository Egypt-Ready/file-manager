# مدير الملفات دون اتصال (Offline File Manager)

تطبيق أندرويد متكامل لإدارة الملفات مبني باستخدام Kotlin و Jetpack Compose مع واجهات Material Design 3 الحديثة. يعمل بالكامل دون الحاجة إلى إنترنت، مع دعم كامل للغة العربية والاتجاه من اليمين إلى اليسار (RTL).

## المميزات الرئيسية
- **نظرة عامة على الذاكرة:** مؤشر بصري للمساحة المستخدمة والمتاحة وتوزيع الأحجام حسب الفئات (مستندات، صور، صوتيات، فيديو، مضغوطات).
- **التصفح السلس:** شريط مسار تفاعلي (Breadcrumb)، عرض قائمة أو شبكة، وفرز حسب الاسم أو التاريخ أو الحجم أو النوع.
- **إدارة الملفات الكاملة:** إنشاء مجلدات وملفات، إعادة التسمية، النسخ، القص، اللصق، الحذف مع معالجة التكرار التلقائية.
- **سلة المحذوفات:** نقل آمن للملفات المحذوفة مع إمكانية استعادتها أو إفراغ السلة بالكامل.
- **محرر نصوص مدمج:** استعراض وتحرير ملفات النصوص البرمجية والمستندات (TXT, MD, JSON, XML) وحفظ التعديلات فوراً.
- **معاينة الوسائط:**
  - عارض للصور بدقة عالية.
  - مشغل صوتي مدمج مع مؤشر تقدم وأزرار التحكم.
- **التعامل مع ملفات ZIP:** ضغط عدة ملفات ومجلدات في أرشيف ZIP وفك الضغط بأمان.
- **العمليات المتعددة:** وضع التحديد المتعدد لنسخ، نقل، حذف، أو ضغط عدة عناصر معاً.
- **حساب البصمة الرقمية (Hash Checksum):** استعراض تفاصيل الملف وحساب بصمة SHA-256 ونسخها.
