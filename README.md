# Offline File Manager (مدير الملفات دون اتصال)

A powerful, native Android file manager built with Kotlin and Jetpack Compose (Material Design 3). Works completely offline with sandboxed local storage, built-in text editor, media previews, ZIP archive management, and trash bin support.

## Features
- **Storage Overview:** Visual storage usage meter with breakdown by category (Documents, Images, Audio, Videos, Archives).
- **File Browsing:** Breadcrumb navigation, List & Grid views, sorting (by Name, Date, Size, Type, Asc/Desc).
- **CRUD Operations:** Create folders, create files, rename, copy, cut, paste, delete, and duplicate auto-naming.
- **Trash Bin / Recycle Bin:** Safe deletion to trash with restore capability and empty trash option.
- **Built-in Text Editor:** In-app viewer and editor for TXT, Markdown, JSON, XML, code, and config files with line count and saving.
- **Media Previews:**
  - Image viewer with smooth loading.
  - Audio player preview with playback controls and wave indicator.
- **ZIP Compression & Extraction:** Compress selected files to ZIP archives, extract ZIP archives with folder generation.
- **Batch Operations:** Multi-selection mode for batch copying, cutting, deleting, sharing, and archiving.
- **Checksum Calculator:** MD5 and SHA-256 hash generator in File Details.
- **Dual Language Support:** Full support for English and Arabic (RTL).
